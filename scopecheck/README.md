# ScopeCheck

An interactive construction scope demo built with GPT-6 Astra.

Open `index.html` directly in a browser. No installation, sign-in, API key or network connection is needed. The page runs entirely in the browser and starts over on reload; use Download review or Export JSON to retain a packet.

## Try it in one minute

1. **Find the hidden risk.** The accepted scope and sum of assignments both read 100 linear feet. However, stations 50–60 are assigned twice and 90–100 have no owner. Unique coverage is only 90 feet.
2. **See a clean handoff.** The external subcontractor owns 0–70; the internal site team owns 70–100. The baseline is covered exactly once.
3. **Add a field request.** A requested 25-foot extension appears beyond the accepted boundary. The accepted baseline stays 100.
4. Adjust station ranges. Acknowledge reviewing the inputs, then edit a value: the acknowledgment clears. Download a readable review or structured JSON with the precise ranges and remaining authorization gap.

All project names, parties, documents and quantities are fictional demonstration data. Only one installation activity is modeled. This is a simplified one-dimensional allocation check, not contract interpretation, a signature, work authorization, cost/schedule analysis or evidence of real-project savings. Astra helped design, implement and test the demo; no model is called while you use it.

Hosted for public demo review. This package does not include any private graph, client files, operational references or credentials.
