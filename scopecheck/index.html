    How this demo checks scope

    We compare both station ranges with the fixed 0–100 lf baseline. A gap has no assigned party; an overlap has two. Touching endpoints are a handoff, not an overlap. Additional requested length stays outside the baseline. This simplified geometry is calculated locally; it does not read or interpret a contract.
